Mujina Miner Object Model

Complete runtime architecture of upstream mujina-miner—covering the Daemon composition root, Backplane hotplug router, Scheduler hub, HashThread actor boundary, hw_trait peripheral stack, Stratum v1 job source, and axum v0 REST/OpenAPI surface.

Channel-Decoupled SubsystemsBackplane, Scheduler, JobSources, and API never call each other directly—all edges are typed mpsc, watch, or oneshot channels.
Trait-Driven Hardware SeamsHashThread unifies single-chip Bitaxe, 12-chip EmberOne, and CPU miners; hw_trait::* lets peripheral drivers run over RHAP-D, Linux buses, or mocks.
Inventory Plugin HotplugBoards self-register via inventory::submit!; Backplane scores USB patterns by specificity and scopes teardown per DeviceKey.
Three-Layer Share FilteringChip TicketMask → per-thread HashTask.share_target (1–10 shares/s) → pool JobTemplate.share_target; structured CancellationToken + TaskTracker exit.

Three Approved Dependency Paths

1. Mining Work & Share Loop

JobSource → mpsc<SourceEvent> → Scheduler → Box<dyn HashThread> (HashTask with per-task share_tx) → ShareStream → SourceCommand::SubmitShare.

2. Board, Peripherals & ASIC Stack

Backplane invokes inventory BoardDescriptor factory → ControlChannel (bitaxe_raw / RHAP-D) provides hw_trait adapters to reusable Peripheral drivers; ASICs speak raw serial bytes directly inside BM13xxThread.

3. Pull-Free Telemetry & Per-Target Commands

Scheduler publishes watch<MinerTelemetry>; each board publishes watch<BoardTelemetry>; api::serve merges them on request and sends commands over target-specific mpsc channels with oneshot replies.

03 Execution, Channel & Trait Contracts

Mujina replaces shared mutable globals with Rust ownership, actor tasks, and explicit async trait/channel boundaries.

Core Rust Contracts (hash_thread.rs, board/mod.rs, messages.rs)

#[async_trait]
pub trait HashThread: Send {
    fn name(&self) -> &str;
    fn capabilities(&self) -> &HashThreadCapabilities;
    async fn configure(&mut self) -> Result<()>;                 // emits ExpectedHashRate
    async fn update_task(&mut self, t: HashTask) -> Result<Option<HashTask>>;  // old valid
    async fn replace_task(&mut self, t: HashTask) -> Result<Option<HashTask>>; // hard wipe
    async fn go_idle(&mut self) -> Result<Option<HashTask>>;
    fn take_event_receiver(&mut self) -> Option<mpsc::Receiver<HashThreadEvent>>;
    fn status(&self) -> HashThreadStatus;
}

pub struct BackplaneConnector {
    pub info: BoardInfo,
    pub threads: Vec<Box<dyn HashThread>>,
    pub telemetry_rx: watch::Receiver<BoardTelemetry>,
    pub shutdown: Option<BoxFuture<'static, ()>>,
}

pub enum SourceEvent   { UpdateJob(JobTemplate), ReplaceJob(JobTemplate), ClearJobs }
pub enum SourceCommand { SubmitShare(Share), UpdateHashRate(HashRate) }
pub enum SchedulerCommand {
    PauseMining  { reply: oneshot::Sender<Result<()>> },
    ResumeMining { reply: oneshot::Sender<Result<()>> },
}

Key Runtime Invariants (Verified at e960d20)

  • Implicit share routing by channel ownership: Each HashTask carries a fresh per-task mpsc::Sender<Share> whose receiver is stored in ShareStream under TaskId. A share arriving on that channel maps unambiguously to its (SourceId, JobTemplate, ThreadId)—dropping the receiver on ReplaceJob / ClearJobs automatically discards stale shares.
  • FIFO startup enumeration gate: Backplane waits for InitialEnumerationComplete from every transport before sending ThreadRegistration::InitialEnumerationComplete on the same FIFO channel after all initial threads. Scheduler's StartupGate holds the first UpdateHashRate broadcast until all starting threads declare ExpectedHashRate (or 10 s timeout).
  • Three-layer share filtering: Chip TicketMask (~1 share/s) → HashTask.share_target clamped between MEASUREMENT_SHARE_RATE (1/s) and FLOOD_CAP_RATE (10/s) for accurate 5-minute HashrateEstimator samples → JobTemplate.share_target for pool submission.
  • Device-scoped hotplug isolation: Backplane keys boards by DeviceKey; unplugging an unrelated USB device is a no-op, unplugging a board stops only that board, and re-attaching on the same key stops the replaced board first.
  • Boards outlive one-shot transports: Even after CPU transport drops its sender, Backplane::run awaits shutdown.cancelled() before calling shutdown_all_boards().
  • Lazy BM13xx chip bring-up & drop-driven cleanup: BM13xxThread starts held in reset and brings up the chain on first work assignment; dropping a board's watch::Sender<BoardTelemetry> causes api::BoardRegistry to prune it lazily.

Why ASICs bypass hw_trait:
  • BM13xx chips speak chip-specific framed serial bytes directly over Stream / ChipCommandSink; the reusable boundary is HashThread above the actor, not a generic bus trait below it.
  • Reader runs as a dedicated subtask demultiplexing unsolicited NonceResponse frames from solicited RegisterResponse frames so register probes never block nonce reception.
